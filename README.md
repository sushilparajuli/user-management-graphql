# User Management GraphQL

This project is a NestJS application for user management with GraphQL.

## Project creation

```bash
nest new user-management-graphql
```

## Install GraphQL dependencies

```bash
yarn add @nestjs/graphql @apollo/server @nestjs/apollo graphql apollo-server-express apollo-server-core
```

## Run the app

```bash
yarn start
```

For development mode:

```bash
yarn start:dev
```

## Useful scripts

```bash
yarn test
yarn run test:e2e
yarn build
```

## Notes

This app uses NestJS with Apollo Server for GraphQL support and is set up as a base for building user-management APIs and schemas.
